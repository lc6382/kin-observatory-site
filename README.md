# kin-observatory-site
Independent Kindroid discovery statistics and historical comparisons. Public viewer and statistics only.

Pages: Kin leaderboard (`/`), creator leaderboard and portfolio explorer (`/creators/`), and the focused Sense Mod World report (`/sense-mod-world/`). All use the same published observation history. Creator statistics cover identifiable handles in the current discovery set, not complete creator accounts. See each page's coverage notes for calculation rules.
